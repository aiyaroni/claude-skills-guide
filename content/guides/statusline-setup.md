## מה זה

הסטטוס-ליין הוא פס קטן בתחתית מסך Claude Code שמראה מידע חי: איזה מודל פועל, כמה מהזיכרון של השיחה נוצל, כמה עלה הסשן ועוד. יש שתי דרכים להוסיף אותו — כלי חינמי בשם ccstatusline, או פקודה מובנית של Claude עצמו. שתיהן לא דורשות לכתוב קוד.

ככה זה נראה אחרי ההגדרה (המחשה):

`Opus > main > 42.3k tokens > $0.42 > 3hr 45m`

## דרך א' — הכלי ccstatusline

1. **פותחים את הכלי.** מדביקים את השורה הבאה בטרמינל ומריצים. נפתח מסך הגדרה עם תצוגה מקדימה חיה בראש:
   `npx ccstatusline@latest`
2. **בוחרים מה יופיע (לא חובה).** במסך שנפתח אפשר לבחור מה יוצג בפס ובאילו צבעים — עם החצים והתצוגה המקדימה. אפשר גם לדלג ולהשאיר את ברירת המחדל.
3. **מתקינים ל-Claude Code.** בוחרים בתפריט "Install to Claude Code", ואז "Save & Exit". מעכשיו כל שיחה חדשה מציגה את הפס.

רוצים לשנות משהו אחר כך? מריצים שוב `npx ccstatusline@latest` ופותחים מחדש את מסך ההגדרה.

ccstatusline הוא כלי חיצוני חינמי, לא של Anthropic. ההתקנה בטוחה ופשוטה, וכל מה שצריך זה השורה שהדבקתם בשלב הראשון.

### מה כדאי להציג בפס

אלה הדברים השימושיים ביותר לרוב האנשים:

- **המודל** — איזה מודל של Claude פועל כרגע
- **ניצול הזיכרון (Context)** — כמה מהשיחה כבר נוצל, כדי לדעת מתי מתקרבים לסוף
- **טיימר הבלוק** — Claude Code עובד בבלוקים של 5 שעות, והטיימר מראה כמה זמן נשאר
- **עלות הסשן** — כמה השיחה הנוכחית עלתה עד כה
- **ענף ה-Git** — למי שעובד עם קוד, על איזה ענף נמצאים

## דרך ב' — הפקודה המובנית של Claude

מי שמעדיף לא להתקין כלום — ל-Claude Code יש פקודה מובנית משלו שמייצרת את הפס. מתארים ל-Claude בשפה חופשית מה רוצים לראות, והוא מכין את הכול לבד.

בתוך Claude Code מקלידים `/statusline` ואחריו תיאור, למשל:

`/statusline show model name and context percentage with a progress bar`

Claude יוצר את הפס, מחבר אותו להגדרות בעצמו, והוא מופיע מיד בתחתית המסך. אפשר לבקש כל דבר בשפה רגילה — למשל "תראה לי את שם המודל בכתום ואת ענף ה-Git".

הפס עוזר לראות במבט אחד כמה מהזיכרון נוצל, כמה עלה הסשן ועל איזה ענף Git נמצאים — ולהבדיל בין כמה חלונות פתוחים במקביל.

להסרה: מקלידים `/statusline delete`.

## סיכום — איזו דרך לבחור

שתי השיטות נותנות בסוף פס דומה, וההבדל הוא רק איך מגדירים אותו:

- **ccstatusline** (דרך א') — פס עשיר עם המון אפשרויות מוכנות, ערכות צבעים וטיימר בלוק. מתקינים פעם אחת עם שורה אחת. מתאים למי שרוצה תוצאה מרשימה בלי להתעסק.
- **הפקודה המובנית** (דרך ב') — לא מתקינים כלום, פשוט מבקשים מ-Claude בשפה חופשית והוא מכין. מתאים למי שרוצה משהו מהיר ומינימלי, בלי כלים חיצוניים.

ההמלצה במדריך: רוצים פס מלא אפשרויות — ccstatusline. רוצים משהו מיידי בלי התקנות — הפקודה המובנית. אפשר גם לנסות אחת ולעבור לשנייה בכל רגע.
