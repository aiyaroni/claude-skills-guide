# coder — חוקים שנלמדו

append-only. תקרה 40 שורות — מעל זה מוחקים לפני שמוסיפים.
חוק נכנס רק מפסילת verifier, מתיקון של ירוני, או מ-/retro באישורו.

- הנרמול העברי ב-`CommandPalette.jsx` (הסרת א' באמצע מילה + ניקוד) עובד. לא לכתוב חיפוש מחדש
- מועדפים ואחרונים ב-localStorage תחת `ysk:`, ממופתחים לפי `cmd`. `id = cmd` לסקילים כדי לא לאבד אותם
- סקילים ב-`~/.claude/skills` מותקנים גם כתיקיות וגם כקישורים סימבוליים (29 מהם). סינון `isDirectory()` בלבד מסמן אותם כלא-מותקנים
