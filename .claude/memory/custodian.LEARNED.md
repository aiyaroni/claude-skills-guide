# custodian — חוקים שנלמדו

append-only. תקרה 40 שורות — מעל זה מוחקים לפני שמוסיפים.
חוק נכנס רק מפסילת verifier, מתיקון של ירוני, או מ-/retro באישורו.

- תיקיית המקור `חומרים על קלוד` מכילה רווחים ועברית. תמיד במרכאות בפקודות shell
- כללי `Write(path)` בהרשאות **לא נאכפים** מול קבצים — רק `Edit(path)`. כלל Write מבוסס-נתיב הוא דקורטיבי
- **לא מוחקים.** קובץ שירוני העביר לעבודה יוצא מ-inbox רק ל-processed או ל-needs-review. אין דרך שלישית
